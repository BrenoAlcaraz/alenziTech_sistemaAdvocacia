Compromissos, audiências e prazos do escritório
🟢 Como as Permissões/Habilitações controlam este módulo
A Agenda segue a mesma lógica geral do resto do sistema. A Permissão "Agenda" (Somente os seus / Todos) define se o usuário só enxerga o próprio calendário ou o de qualquer pessoa do escritório — quando é "Todos", ele ganha acesso à aba "Agenda de outros usuários", lá embaixo. Já a Habilitação "Adicionar compromisso para outros" (dentro de Agenda, em Habilitações) decide se, ao criar um compromisso, ele pode marcar pra outras pessoas ou só pra si mesmo — se estiver desligada, o campo "Agenda de" vem travado só nele mesmo.
🔴 Como construir
Consulte permissoes_papel.agenda.sub_opcao do usuário logado: se 'todos', libere a aba "Agenda de outros usuários" (adicionalmente gateada pela habilitação de Gerir "Habilitar terceiros" ou "Adicionar compromisso para outros", dependendo de como for modelado — mesma ideia já usada em Tarefas pra "Tarefas de outros usuários"); se 'somente_seus', esconda essa aba. Consulte também habilitacoes_papel.agenda.adicionar_para_outros: se false, no formulário "Novo compromisso" o campo "Agenda de" deve vir travado só no próprio usuário. Replique as duas checagens no backend — nunca confie só em esconder no frontend.
Voltar
É possível criar o compromisso na sua própria agenda, na de outro usuário, ou em várias agendas ao mesmo tempo — basta marcar cada uma na lista, ou usar o atalho "Selecionar todos".

🟢 Marcando mais de uma pessoa
Dá pra criar o mesmo compromisso pra várias pessoas ao mesmo tempo — útil pra reunião de equipe, por exemplo, em vez de criar um por um. Esse campo só aparece liberado (com as outras pessoas selecionáveis) se o usuário tiver a habilitação "Adicionar compromisso para outros"; sem ela, ele só consegue marcar compromisso pra si mesmo.
🔴 Como construir
Ao renderizar o formulário, cheque habilitacoes_papel.agenda.adicionar_para_outros do usuário logado: se false, troque a lista de checkboxes por um campo fixo (só o próprio usuário). Ao salvar, para cada usuário marcado, crie uma linha em eventos_agenda (não um evento com múltiplos responsáveis — uma linha por pessoa, com responsavel_id, criado_por: usuario_logado.id, data_criacao: hoje). No backend, mesmo que o frontend esconda o campo, a rota de criação deve recusar (403) se responsavel_id !== usuario_logado.id e a habilitação estiver desligada.

🟢 Compromisso periódico
Serve pra compromissos que se repetem sempre — uma reunião de equipe toda semana, o vencimento mensal de uma obrigação, um retorno periódico com um cliente. Em vez de criar manualmente todo mês, o sistema já gera as próximas ocorrências de uma vez, cada uma como um compromisso independente no calendário (pode ser concluída, cancelada ou reagendada isoladamente, sem afetar as demais).
🔴 Como construir
Gere um recorrencia_id compartilhado e crie de uma vez as N ocorrências pedidas (não uma por vez via cron) — cada uma com a data avançando pela frequência escolhida (semanal = +7 dias, mensal = +1 mês, personalizada = +X dias) a partir da primeira. Todas nascem com status: 'agendado', nunca já concluídas. Cada ocorrência é um evento independente em eventos_agenda — só compartilham o recorrencia_id pra referência (não é um evento "mestre" com sub-itens).

🟢 O que é
Notifica todos os compromissos que entraram na agenda do usuário nas últimas 24 horas, não importa quem criou — pode ser ele mesmo, um colega, ou a IA (identificando um prazo a partir de um andamento do processo, por exemplo). É a forma rápida de ver "o que apareceu de novo pra mim" sem precisar navegar o calendário inteiro procurando.
🔴 Como construir
Filtre eventos_agenda WHERE responsavel_id = usuario.id AND data_criacao >= now() - 24h, sem filtrar por criado_por — o objetivo é pegar qualquer origem. Ordene por data_criacao DESC. O contador no badge é só o COUNT() desse mesmo filtro.
🟢 O que é
Mostra os compromissos que outra pessoa colocou na sua agenda — qualquer colega do escritório, não só quem está acima na hierarquia. Um advogado com papel Ilimitado pode perfeitamente marcar um compromisso na agenda de outro colega do mesmo papel, não só o mestre ou um superior organizando a agenda de baixo.
🔴 Como construir
Filtre eventos_agenda WHERE responsavel_id = usuario.id AND criado_por != usuario.id — qualquer criador diferente do próprio responsável entra aqui, sem checar hierarquia. Igual fizemos em Tarefas, não precisa de nenhuma lógica de superior_id pra essa aba funcionar.
🟢 O que é
É o espelho da aba anterior: aqui o usuário vê todos os compromissos que ele mesmo colocou na agenda de outras pessoas, e pode acompanhar o status de cada um (agendado, concluído, cancelado) — útil pra quem organiza a agenda da equipe saber se o que foi marcado pra alguém realmente aconteceu.
🔴 Como construir
Filtre eventos_agenda WHERE criado_por = usuario.id AND responsavel_id != usuario.id — o oposto exato do filtro da aba "Adicionado por terceiro". Essa aba só aparece pra quem tem a habilitação "Adicionar compromisso para outros" ligada (a mesma que libera o campo "Agenda de" no formulário) — só faz sentido ver o que você delegou se você pode delegar.
Disponível para quem tem a Permissão "Agenda" em "Todos" e a habilitação de Gerir correspondente. Veja a agenda de qualquer usuário do escritório e adicione compromissos diretamente nela.
🟢 O que é
Permite consultar (e adicionar compromissos n)a agenda de qualquer pessoa do escritório — útil pro gestor organizar a rotina de alguém, ou verificar rapidamente a disponibilidade de um colega antes de marcar algo. Não é mais exclusivo do mestre: qualquer usuário com a Permissão "Agenda" em "Todos" (e a habilitação de Gerir correspondente) enxerga essa aba.
🔴 Como construir
Essa aba só renderiza se permissoes_papel.agenda.sub_opcao === 'todos' — mesma checagem já usada pra liberar o card "Compromissos próximos" completo no Painel. Ao selecionar um usuário no seletor, busque eventos_agenda WHERE responsavel_id = usuario_selecionado.id. O botão "+ Novo compromisso nesta agenda" reaproveita o mesmo formulário de criação, só que com o campo "Agenda de" pré-preenchido e travado nesse usuário.
