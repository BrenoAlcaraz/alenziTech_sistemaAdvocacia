# Specs em andamento

de negócio, fora do escopo, plano técnico resumido, tarefas, critérios
de aceite). Apagado ao concluir — ver a regra de promoção de
conhecimento durável em [AGENTS.md](../AGENTS.md#antes-de-apagar-uma-spec-concluída).
